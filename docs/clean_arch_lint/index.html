clean_arch_lint

clean_arch_lint library

Analyzer plugin that enforces Flutter Clean Architecture layer boundaries.

Isolation is checked by inspecting import directives (AST), not by code generation. Each diagnostic is its own rule, so it can be enabled or disabled independently; all of them share the layer resolution in ArchitectureImportRule.

Layers (lib/{layer}/ or lib/src/{layer}/):

  • domain: innermost; may import only other domain files and pure Dart libraries (dart:core, dart:async, ...); dart:ui, dart:io, Flutter and third-party packages are not allowed
  • core: must not import screens or presentation
  • data: must not import screens or presentation
  • presentation: must not import data
  • screens: must not import data

Diagnostics

Code When it fires
no_data_dependencies presentation/screens import data
no_screens_dependencies data/core import screens or presentation
domain_only_depends_on_itself domain imports anything outside domain, except pure Dart libraries

allow_third_party_packages_in_domain is an option, not a check: when enabled, domain_only_depends_on_itself stops reporting third-party packages (package:equatable/...). Flutter SDK packages, dart:ui, dart:io and the other layers stay reported. It is off by default.

Lint rules from analyzer plugins are disabled by default. Enable them in the top-level plugins section of analysis_options.yaml.

Local checkout:

plugins:
  clean_arch_lint:
    path: ../clean_arch_lint
    diagnostics:
      no_data_dependencies: true
      domain_only_depends_on_itself: true
      no_screens_dependencies: true

Published package:

plugins:
  clean_arch_lint:
    version: ^3.0.0
    diagnostics:
      no_data_dependencies: true
      domain_only_depends_on_itself: true
      no_screens_dependencies: true

Add allow_third_party_packages_in_domain: true to allow third-party packages in domain.

Use error instead of true to raise severity. Suppress with // ignore: clean_arch_lint/no_data_dependencies.

Classes

AllowThirdPartyPackagesInDomainRule
Option that lets domain_only_depends_on_itself allow third-party packages in domain. It never reports anything.
CleanArchitectureLintPlugin
Registers the architecture rules with the analysis server.
DomainOnlyDependsOnItselfRule
Reports domain importing anything outside domain, except the pureDartLibraries (dart:core, dart:async, dart:collection, dart:convert, dart:math, dart:typed_data).
NoDataDependenciesRule
Reports presentation or screens importing data.
NoScreensDependenciesRule
Reports data or core importing screens or presentation.
